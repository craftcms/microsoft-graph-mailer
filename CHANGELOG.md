# Release Notes for Microsoft Graph Mailer

## 1.1.0 - 2026-11-12

- Added Craft 6 compatibility, when the `craftcms/yii2-adapter` package is installed. Craft keeps sending email through the Microsoft Graph settings in the project config until a Laravel mailer is configured. ([Craft 6 instructions](https://github.com/craftcms/microsoft-graph-mailer/blob/1.x/README.md#craft-6))
- Added support for `symfony/mailer` and `symfony/microsoft-graph-mailer` 8.x.
